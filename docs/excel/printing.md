# Printing

Print behavior is configured per worksheet: page setup, margins, print
options, the print area, repeated title rows and columns, and page headers
and footers.

```cpp
#include "ExyokiOffice/Excel/ExcelDocument.hpp"
using namespace ExyokiOffice::Excel;
```

## Page setup and margins

```cpp
sheet->SetPageSetup(PageSetup{.Orientation = PageOrientation::Landscape,
                              .PaperSize = PaperSize::A4,
                              .FitToWidth = 1});
sheet->SetPageMargins(PageMargins{.Left = {1.0, MeasurementUnit::Centimeter}});
```

`PageSetup` covers orientation, paper size (the full OOXML paper-size
catalog), scaling — either a fixed percentage or fit-to-width/height page
counts — and the first page number. Margins take any physical unit. Every
setter has a matching getter (`GetPageSetup`, `GetPageMargins`, and so on
for the rest of this chapter).

## Print options, area, and titles

```cpp
sheet->SetPrintOptions(PrintOptions{.HorizontalCentered = true, .GridLines = true});
sheet->SetPrintArea({*CellRange::ParseA1("A1:E20")});
sheet->SetPrintTitles(PrintTitles{.Rows = std::pair<UInt32, UInt32>{3, 3}});
```

`PrintOptions` controls centering and whether gridlines and headings print.
The print area accepts multiple ranges; print titles repeat the given row
span (and/or column span) on every printed page. Under the hood both are
stored as the built-in defined names `_xlnm.Print_Area` and
`_xlnm.Print_Titles`, which is why a workbook usually lists more
[named ranges](named-ranges.md) than were created explicitly.

## Headers and footers

```cpp
sheet->SetHeaderFooter(HeaderFooter{.OddHeader = "&LQuarterly sales&RGenerated by ExyokiOffice",
                                    .OddFooter = "&CPage &P of &N"});
```

Header and footer strings use Excel's own formatting codes (`&L`/`&C`/`&R`
select the left/center/right section, `&P` and `&N` insert the page number
and page count, `&D` the date, `&F` the file name); they are stored
verbatim. Separate even-page and first-page strings are available on the
same structure.
